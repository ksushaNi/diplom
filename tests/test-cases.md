# Тест-кейсы для сайта ресторана "Бархат"

## TC_01 - Авторизация пользователя
|Параметр|Значение|
|----------|----------|
|приоритет|высокий|
|предусловие|пользователь зарегистрирован в системе (логин "admin@mail.ru", пароль "12345")|
|шаги|1. Открыть главную страницу<br> 2. Нажать кнопку "Авторизация" <br> 3. Ввести логин `admin@mail.ru` <br> 4. Ввести пароль `123456` <br> 5. Нажать кнопку "Вход"|
|ожидаемый результат|происходит перенаправление на главную страницу|
|фактический результат|произошло перенаправление на главную страницу|
|статус|успешно|

## TC_02 - Проверка фильтрации товаров
|Параметр|Значение|
|----------|----------|
|приоритет|средний|
|предусловие|в каталоге есть товары разных категорий|
|шаги|1. Перейти на главную страницу с меню<br> 2. Выбрать категорию "Супы"|
|ожидаемый результат|отображаются только товары из категории "Супы"|
|фактический результат|отображаются товары из категории "Супы"|
|статус|успешно|

## TC_03 - Оформление заказа 
|Параметр|Значение|
|----------|----------|
|приоритет|средний|
|предусловие|в корзину добавлено 2 товара, пользователь авторизован|
|шаги|1. Перейти в корзину<br> 2. Ввести адрес доставки и номер телефона<br> 3. Нажать кнопку "Оформить заказ"|
|ожидаемый результат|происходит перенаправление на главную страницу с меню, а в админ-панели появляется заказ в статусе "новый"|
|фактический результат|происходит перенаправление на главную страницу с меню, а в админ-панели появляется заказ в статусе "новый"|
|статус|успешно|
